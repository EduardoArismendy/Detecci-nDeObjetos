# 🧠 Detector de Objetos

**Detector de Objetos** es una web interactiva que utiliza tecnologías de visión por computadora para identificar objetos en imágenes o video en tiempo real. Basada en la demo original publicada en [detectordeobjetos.netlify.app](https://detectordeobjetos.netlify.app), esta versión sirve como base para expandir esta funcionalidad en un proyecto colaborativo y educativo.

---

## 🎯 ¿Qué hace actualmente?

- Procesa imágenes o vídeo desde tu cámara o archivos locales
- Detecta y resalta objetos comunes (personas, vehículos, animales, etc.)
- Muestra etiquetas y cuadros delimitadores en tiempo real
- Interfaz web ligera y responsiva
- Desplegada en Netlify para acceso instantáneo

---

## 🧬 Inspiración: la demo original

La página original permite probar detección de objetos sin instalar nada. La demo es funcional y proporciona resultados rápidos, demostrando el potencial del machine learning en el navegador. Este proyecto reutiliza esa esencia e ideas para:

- Reestructurar el código con componentes
- Añadir documentación y pruebas
- Crear una base colaborativa abierta

---

## 🚧 Tecnologías usadas

- **TensorFlow.js** o **ml5.js** para detección en navegador
- **React.js** (o framework similar)
- **Tailwind CSS** o CSS puro
- **JavaScript ES6+**
- Despliegue continuo en Netlify
